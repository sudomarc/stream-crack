StreamCrack

Outil Rust d'audit et de récupération de mots de passe Wi-Fi WPA2 avec interface terminale TUI. Conçu pour les audits autorisés, le traitement local et l'efficacité sur machines aux ressources limitées.

Installer via APT Voir les fonctionnalités
✔ Version 0.1.0 disponible

Fonctionnalités

Audit de captures PCAP/PCAPNG

Lecture bornée des fichiers de capture, validation des longueurs et offsets, classification des frames 802.11, rapports de métadonnées assainies (JSON et texte).

Extraction de handshake WPA2

Rassemble les frames EAPOL-Key d'un handshake 4-way depuis une capture, avec récupération du SSID via les balises beacon.

Récupération hors-ligne du PSK

Vérification du MIC WPA2 (PBKDF2-HMAC-SHA1, PTK, KCK) par attaque dictionnaire ou masque, avec plafonnement des candidats, progression et annulation.

Interface TUI

Interface terminale clavier-driven avec écrans Résumé, Trames et Aide. Navigation fluide, redimensionnement, états d'erreur et de progression.

Sûr par construction

Aucune donnée de payload, clé ou credential n'est jamais affichée ni journalisée. Tous les fichiers d'entrée sont traités comme non fiables.

Local et sans réseau

Aucune dépendance réseau requise pour l'usage ordinaire. Traitement entièrement local des fichiers de capture.

Installation

1

Ajouter le dépôt APT StreamCrack

Ajoutez la source APT signée au gestionnaire de paquets.

echo "deb [signed-by=/etc/apt/keyrings/streamcrack.gpg] https://sudomarc.github.io/stream-crack/apt/ stable main" | sudo tee /etc/apt/sources.list.d/streamcrack.list
sudo mkdir -p /etc/apt/keyrings
curl -fsSL https://sudomarc.github.io/stream-crack/apt/streamcrack.gpg | sudo tee /etc/apt/keyrings/streamcrack.gpg > /dev/null
2

Installer le paquet

sudo apt update
sudo apt install streamcrack
3

Téléchargement direct (.deb)

Téléchargez le dernier paquet .deb depuis la page Releases GitHub, puis installez :

curl -LO https://github.com/sudomarc/stream-crack/releases/download/v0.1.0/streamcrack_0.1.0-1_amd64.deb
sudo apt install ./streamcrack_0.1.0-1_amd64.deb

⚠ Le paquet n'est proposé que s'il a été publié. Vérifiez toujours la version sur la page Releases.

4

Depuis les sources

git clone https://github.com/sudomarc/stream-crack.git
cd stream-crack
cargo build --release

Le binaire se trouve dans target/release/streamcrack.

5

Mise à jour

sudo apt update
sudo apt upgrade streamcrack
6

Désinstallation

sudo apt remove streamcrack

Utilisation

Inspecter un capture

streamcrack capture.pcap

Affiche un résumé des métadonnées : format, link type, nombre de paquets, octets capturés, horodatages, diagnostics.

Lancer la TUI

streamcrack --tui capture.pcap

Interface terminale avec écrans Résumé, Trames, Aide. Touches : j/k sélection, Tab écrans, q quitter.

Récupérer un PSK

streamcrack --crack --wordlist wordlist.txt capture.pcap

Attaque dictionnaire autorisée uniquement sur réseaux dont vous avez l'autorisation. Masque possible avec -m.

> streamcrack --tui capture.pcap
— StreamCrack inspection —
format: Pcapng
packets: 42
captured bytes: 8192
link type: IEEE 802.11
diagnostics: 0 entries
q:quit ?:help Tab:screens j/k:select

Dépannage

« commande introuvable » après l'installation

Vérifiez que /usr/bin est dans votre PATH, puis relancez votre shell ou ouvrez un nouveau terminal.

Signature APT invalide

Ré-importez la clé publique depuis /stream-crack/apt/streamcrack.gpg et regénérez les fichiers de cache APT (sudo apt update).

Aucun handshake trouvé

Le fichier de capture ne contient pas deux frames EAPOL-Key sur une même paire d'adresses MAC. Vérifiez que le fichier est bien une capture WPA2 avec handshake complet.
